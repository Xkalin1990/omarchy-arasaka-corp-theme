# arasaka-ghostty

Custom Ghostty terminal theme & graphics setup tailored for Omarchy's `arasaka-corp` theme:

- Centered low-opacity Cyberpunk 2077 Samurai oni-mask watermark (`assets/samurai-logo.png`)
- Full-window subtle CRT + crimson HUD corner shader (`shaders/arasaka-hud.glsl`)
- Custom GTK CSS preserving glass blur with `arasaka-corp` chrome + bottom-right netrunner status (`gtk-arasaka.css`)

## Install on Another Machine

```bash
git clone https://github.com/Xkalin1990/arasaka-ghostty.git
cd arasaka-ghostty
./install.sh
```

Then press `Ctrl+Shift+,` in Ghostty (or open a new window).
